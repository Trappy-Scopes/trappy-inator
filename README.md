# trappy-inator

trappy-inator is the template and project that every Trappy-Scopes instrument starts from.

The name is actually inspired by a cartoon called Phineas and Ferb, which has a comical villain, Dr. Heinz Doofenshmirtz, who is very funny and who names everything with the suffix "-inator". His first machine was actually called an Inator, so this is like a wordplay.

This website is the showcase for that template. Every Trappy-Scopes instrument keeps its 3D-printed parts as parametric OpenSCAD source files. From those files the website is built automatically: printable STL and 3MF files, a 3D view of every part and assembly, a bill of materials, and assembly and disassembly instructions. Every part carries its version, so the exact file you printed can be linked and cited.

To show the whole workflow on something small, this project contains a single model: a to-scale facsimile of *Chlamydomonas reinhardtii*, the green alga at the centre of our work. Its cell body, eyespot and two flagella are separate parts that together form one assembly.

In the **Playground** you can change every parameter of the cell, from its shape to the length of each flagellum, and see the result in 3D straight away. OpenSCAD runs in your own browser, so the model you download is generated from exactly the parameters you chose. **How it works** explains how the files, renders and citations are produced.
